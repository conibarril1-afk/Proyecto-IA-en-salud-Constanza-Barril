# Proyecto-IA-en-salud-Constanza-Barril
Pipeline de análisis de señales de fluorescencia celular para estudiar actividad basal/pre-peak. Incluye extracción de ROIs, normalización ΔF/F₀, detección de eventos, clustering no supervisado con UMAP/K-means y validación exploratoria con dataset externo GCaMP6m.
